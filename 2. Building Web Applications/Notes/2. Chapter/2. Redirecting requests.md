Redirecting requests are common in any web applications

Reasons for it:
- a non-canonical address may need to be redirected to the canonical one for SEO purposes or for changes in site architecture
- Redirecting after a successful or unsuccessful POST. This helps us to prevent rePOSTing of the same form data accidentally
- The page is not necessarily missing, but it now lives in another location.
