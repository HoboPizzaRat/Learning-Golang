Gorilla is less of a framework and more of a set of very useful
tools that are generally bundled in frameworks

gorilla/context:
- is for creating globally accessible variable from the request
- useful for sharing a value from the url without repeating the code to access it across your application

gorilla/rcp
- implements rpc-json
	- system for remote code services and communication
- uses json format to define the intentions of requests

gorilla/schema
- allows packing a form variables into struct.(pain in the ass otherwise)

gorilla/securecookie
- implements authenticated cookies and encrypted cookies for your application

gorilla/sessions
- similar to cookies
- provides unique, long-term data stores
	- using file or cookie based session system

gorilla/mux
- allows creating flexible routes that allow regular expression so dictate variables for routers

gorilla/reverse
- allows you to reverse the process of creating regular expression based muxes.
