a map is implemented as a pointer to a struct. 
- Passing a map to a function means that you are copying a pointer.

Because of this, you should avoid using maps for input parameters or return values,
especially on public APIs.
- pointers are bad choice cuz they wont say anythign about the data within
- its not self documenting then

Meanwhile, passing a slice to a function has more complicated behavior: any modifi‐
cation to the contents of the slice is reflected in the original variable
- the slice is implemented with 3 fields 
	- int field of length, int field for capacity, and a pointer to a block of memory
