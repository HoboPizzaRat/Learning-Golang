The & operator is the address operator
- it returns the address of the memory location where the value is stored

The \* is the indirection operator. It precedes a variable of pointer type and
returns the pointer to value.
- the action is called dereferencing

Make sure that when you dereference a pointer, its not nil. 
- the program will panic when you attempt to dereference a nil pointer

```go
var x *int
fmt.Println(x == nil) // prints true
fmt.Println(*x) // panics
```

Pointer type is a type that represents a pointer.
- its written with \* before the type name.
- the pointer type can be of any type
```go
x := 10
var pointerToX *int
pointerToX = &x
```
