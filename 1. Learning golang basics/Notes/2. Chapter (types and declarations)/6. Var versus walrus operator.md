Go has many ways to declare variables

The most verbose way to declare a variable in Go uses the var keyword, an explicit
type, and an assignment. It looks like this:

```go
var x int = 10
```

though you can also do this with integer literals(not recommended)
```go
var x = 10
```


You can declare multiple variables via separating them
```go
var x, y int = 10, 20
```


 you can use the := operator to replace a var declaration that uses type inference.

 ```go 
 x := 10
 ```
You should rarely declare variables outside of functions, in what’s called the package
block
