Methods in Go are so much like functions that you can use a method as a replace‐
ment for a function any time there’s a variable or parameter of a function type

In the case of a method expression, the first parameter is the receiver for the method

```go
type Adder struct {
	start int
}
func (a Adder) AddTo(val int) int {
	return a.start + val
}

myAdder := Adder{start: 10}
fmt.Println(myAdder.AddTo(5)) // prints 15
```


## functions versus methods
So when use when?
- depends whether or not your function depends on other data.
- otherwise said if your functions depends solely on the input parameters, then its a function
- if you have so that your function changes values of the objects or struct that its tied on, then you already know you should use method.
