Its is done with either via for loop or the 
```go
m := map[string]int{
"a": 1,
"c": 3,
"b": 2,
}
for i := 0; i < 3; i++ {
	fmt.Println("Loop", i)
	for k, v := range m {
		fmt.Println(k, v)
}


```
Take a note that the values varies from the given output on every loop iteration
- its a security feature
	- people could just assume the order was fixed, and this would break at times
	- if maps always hash items to the exact same values and you know the server stores data in a map, you can do the *hash dosh* attack to slow the server down by filling up the hashmap bucket that stores values.
