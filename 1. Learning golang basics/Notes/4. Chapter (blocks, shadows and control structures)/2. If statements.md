in go the if statements are rather simple
- most notable change compared to other languages is that you dont put parenthesis around the condition.
```go
n := rand.Intn(10)
if n == 0 {
	fmt.Println("That's too low")
} else if n > 5 {
	fmt.Println("That's too big:", n)
} else {
	fmt.Println("That's a good number:", n)
}
```
