A shadowing variable is a variable that has the same name as a variable in a contain‐
ing block. 
- as long as the shadowing variable exists, you cannot acces a shadowed variable
- otherwise said if you define a variable in inner scope, you cannot access the same named outerscoped variable until you exit the block where the inner variable is defined.

```go
func main() {
	x := 10
	if x > 5 {
		x, y := 5, 20
		fmt.Println(x, y)
	}
	fmt.Println(x)
}
// outputs
// 5 20
// 10
```
Take a note that it can also be inside a if statement the shadowing, not necessarily for it to be a function as long as its been wrapped with {}

Take a note that you might accidentally shadow a existing package functions if we use the same named variable names as are inside the packages etc
