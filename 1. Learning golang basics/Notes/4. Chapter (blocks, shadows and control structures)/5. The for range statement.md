What makes a for-range loop interesting is that you get two loop variables
- first value is the position in the data structure being iterated
- the second value is the value at that position


```go

evenVals := []int{2, 4, 6, 8, 10, 12}

for i, v := range evenVals {
	fmt.Println(i, v)
}
//outputs:
// 0 2
// 1 4
// 2 6
// 3 8
// 4 10
// 5 12
```

If you only want to access the value but not keys?, you need to do a little conversion, since golang doesn't allow to declare any variables that are not used int he functions.
Solution? The _ as the variable name. The underscore is ignored by go compiler
```go
evenVals := []int{2, 4, 6, 8, 10, 12}
for _, v := range evenVals {
	fmt.Println(v)
}
```

If you want teh key instead but not the value, we can do:
```go
uniqueNames := map[string]bool{"Fred": true, "Raul": true, "Wilma": true}
for k := range uniqueNames {
	fmt.Println(k)
}
```
