As in other languages in the C family, Go uses a for statement to loop. What makes
Go different from other languages is that for is the only looping keyword in the lan‐
guage. Go accomplishes this by using the for keyword in four different formats:

- A complete, C-style for
- A condition-only for
- An infinite for
- for-range

example of regular for
```go
for i := 0; i < 10; i++ {
	fmt.Println(i)
}

```

you can make infinite loop just by omitting the init, cond and iter parts
```go
package main
import "fmt"

func main() {
	for {
		qfmt.Println("Hello")
	}
}

```
