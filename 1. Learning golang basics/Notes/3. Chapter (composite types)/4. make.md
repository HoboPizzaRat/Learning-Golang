The make function allows us to specify the type, length and optionally the capacity for the object in memory.

```go
x := make([]int, 5)
```

One common beginner mistake is to try to populate initial elements using
append:
```go
x := make([]int, 5)
x = append(x, 10)
```

The 10 is placed at the end of the slice, after the zero values in positions 0–4 because
append always increases the length of a slice. The value of x is now [0 0 0 0 0 10], with
a length of 6 and a capacity of 10 (the capacity was doubled as soon as the sixth ele‐
ment was appended)

we should instead just specify the initial capacity with make.
- the following makes slice with length of 5 but capacity of 10
```go
x := make([]int, 5, 10)
```

Though take a note that every time you define somethign with length 0 but capacity something, you cannot access the values of the slice, until you have appended some values onto it.
```go
x := make([]int, 0, 10)
x = append(x, 5,6,7,8)
```
