Golang has the tendency to make most functions return a two variables, in which the first one is the value and the second is the error if any has happened
- in the case of map the ok value is a bool representing whether the value is present
```go
m := map[string]int{
	"hello": 5,
	"world": 0,
}

v, ok := m["hello"]
fmt.Println(v, ok)

v, ok = m["world"]
fmt.Println(v, ok)

v, ok = m["goodbye"]
fmt.Println(v, ok)

```
