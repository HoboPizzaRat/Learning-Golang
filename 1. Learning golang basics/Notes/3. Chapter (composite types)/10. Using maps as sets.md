Go doesn’t include a set, but you can use a map to simulate some of its features. Use
the key of the map for the type that you want to put into the set and use a bool for the value

example
```go
intSet := map[int]bool{}
vals := []int{5, 10, 2, 5, 8, 7, 3, 9, 1, 2, 10}
for _, v := range vals {
	intSet[v] = true
}
fmt.Println(len(vals), len(intSet))
fmt.Println(intSet[5])
fmt.Println(intSet[500])
if intSet[100] {
	fmt.Println("100 is in the set")
}
```

In this case you have a two sets of data collection.
- 1. The first one is an array/slice that stores the actual values called vals
- 2. the second one is a map that contains all the boolean values in place on all the key values that are the values of the vals array
So whenever we add value to the vals, we check if there exists key on the intSet map.
- if it doenst exist or returns false, we add the int value to the vals and then set the key on intSet to true on the given integer value.
- if the intSet returns true with given key it means it has been added to the vals slice.
