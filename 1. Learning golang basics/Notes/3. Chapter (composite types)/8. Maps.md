you can use a var declaration to create a map variable that’s set to
its zero value:

```
var nilMap map[string]int
```

Attempting to read a nil map always returns the zero value for the map’s value type. However, attempting to write to a nil map variable causes a panic

We can still create an empty map that isn't the same as nil map. In the following case we are using empty map literal
```go
totalWins := map[string]int[]
```

And this is an example of nonempty map literal
```go
teams := map[string][]string {
	"Orcas": []string{"Fred", "Ralph", "Bijou"},
	"Lions": []string{"Sarah", "Peter", "Billie"},
	"Kittens": []string{"Waldo", "Raul", "Ze"},
}
```

You can also create a map with predefined length if you know how many key value pairs it will contain.
```go
ages := make(map[int][]string, 10)
```

- maps created with make can still go over the specified size
- they still have the length of 0 as of start

## maps are like slices
- they automatically grow as you add values to them
- if you know the amount of key value pairs that the map has, you can use make to create the map with specified size
- passing a map to the len function tells the amount of key value pairs it has
- the zero value for a map is nil
- maps are not comparable. You can check if they are equal to nil, but cannot check whether two maps are identical using == or != 
- key of map cannot be any other than comparable type.
- golang maps are basically hashmaps internally


```go
totalWins := map[string]int{}
totalWins["Orcas"] = 1
totalWins["Lions"] = 2
fmt.Println(totalWins["Orcas"])
fmt.Println(totalWins["Kittens"])
totalWins["Kittens"]++
fmt.Println(totalWins["Kittens"])
totalWins["Lions"] = 3
fmt.Println(totalWins["Lions"])
// output
// 1
// 0
// 1
// 3
```
## deleting from maps
Key-value pairs are removed from a map via the built-in delete function:
```go
m := map[string]int{
	"hello": 5,
	"world": 10,
}
delete(m, "hello")
```
