You can also declare that a variable implements a struct type without first giving the
struct type a name. This is called an anonymous struct:v

```go

var person struct {
	name string
	age int
	pet string
}

person.name = "bob"
person.age = 50
person.pet = "dog"

// here is an anonymous strcut
pet := struct {
	name string
	kind string
}{
	name: "Fido",
	kind: "dog",
}
```

## why use anonymous structs?
its common in situations where you have just the general outlayout for data and don't need to rly define the data for a specific type
- so parsing json or protocol buffers
- this is also called unmarshaling and marshaling data
