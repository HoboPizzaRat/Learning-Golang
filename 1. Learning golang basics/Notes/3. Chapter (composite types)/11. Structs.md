maps are not an ideal way to pass data from function to function. When you have
related data that you want to group together, you should define a struct.

## defining struct
```go
type person struct {
	name string
	age int
	pet string
}
```
The struct type is defined with the keyword type. 
And the data is wrapped around {} characters

Once struct type has been declared we can define variables of that type with 
```go
var fred person
```

We can assign a struct literal to a variable as well

Also: A struct literal can be specified as a comma-separated list of values for the fields inside of braces:
```go
julia := person{
	"Julia",
	40,
	"cat",
}
```

We can also assign the names of the variables in the struct definition.
```go
beth := person{
	age: 30,
	name: "Beth",
}
```
- When you use this style, you can leave out keys and specify the fields in any order.
- any fields not specified in this manner gets its corresponding zero value
