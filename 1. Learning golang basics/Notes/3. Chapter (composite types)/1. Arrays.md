All items in the array are the same type in golang

There are few declaration styles for arrays

This one specifies array of integers(note that preferred type should be int64) of length 3(can contain 3 integers)
```go
var x[3]int
```

if you want to specify initial values for the array, then specify them with array literal
```go
var x = [3]int{10, 20, 30}
```

if you have sparse array, you can specify only the indices with values in the array literal
```go
var x = [12]int{1, 5:4, 6, 10:100, 15}
// this creates the following array
// [1, 0, 0, 0, 0, 4, 6, 0, 0, 0, 100, 15]
```


When you want to set the array length when initializing array, you can leave off the number and use ... instead
```go
var x = [...]int[10, 20, 30]
```

Go only has one-dimensional arrays, but you can simulate multidimensional arrays
```go
var x[2][3]int
```
- This declares x to be an array of length 2 whose type is an array of ints of length 3.
- its not a real matrix in a sense


 the built-in function len takes in an array and returns its length:
 ```go
 fmt.Println(len(x))
 ```


Due to the limitations of golang, don't use arrays unless you know the exact length you need ahead of time.
