Slices aren’t the only thing you can slice. If you have an array, you can take a slice
from it using a slice expression.
 
However, be aware that taking a slice from an array has the
same memory-sharing properties as taking a slice from a slice. 

## copy
If you need to create a slice that’s independent of the original, use the built-in
copy function. 
```go
x := []int{1, 2, 3, 4}
y := make([]int, 4)
num := copy(y, x)
fmt.Println(y, num)
```
The copy function takes two parameters. The first is the destination slice and the sec‐
ond is the source slice. It copies as many values as it can from source to destination,
limited by whichever slice is smaller, and returns the number of elements copied.

The copy function allows you to copy between two slices that cover overlapping sections of an underlying slice
````go
x := []int{1, 2, 3, 4}
num = copy(x[:3], x[1:])
fmt.Println(x, num)
```
