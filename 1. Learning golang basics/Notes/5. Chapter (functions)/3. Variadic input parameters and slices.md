
This is how we can define a variadic function that takes varying amount of values
	- fist paremeter is the amount we add to each element on the slice
	- the second parameter is size varying slice whose values we operate on
	- take a note that we create new slice that we return without changing the values of the input parameters.(best practise)
```go
func addTo(base int, vals ...int) []int {
	out := make([]int, 0, len(vals))
	for _, v := range vals {
		out = append(out, base+v)
	}
	return out
}
```

We can call this function in many ways
```go
func main() {
	fmt.Println(addTo(3))
	fmt.Println(addTo(3, 2))
	fmt.Println(addTo(3, 2, 4, 6, 8))
	a := []int{4, 3}
	fmt.Println(addTo(3, a...))
	fmt.Println(addTo(3, []int{1, 2, 3, 4, 5}...))
}
```
