You can pass other functions as parameters to functions.

One example is sorting slices. There’s a function in the sort package in the standard
library called sort.Slice. It takes in any slice and a function that is used to sort the
slice that’s passed in

example
```go
type Person struct{
	FirstName string
	LastName string
	Age int
}
people .= []Person{
	{"Pat". "Patterson", 37},
	{"Pat". "Patterson", 37},
	{"Pat". "Patterson", 37},
}
fmt.Println(people)

// we sort the items of the people struct list by property LastName
sort.Slice(people, func(i int, j int) bool {
	return people[i].LastName < people[j].LastName
})
fmt.Println(people)

// we can also sort by the age
sort.Slice(people, func(i int, j int) bool {
	return people[i].Age < people[j].Age
})
fmt.Println(people)
```
