Go doesn’t have: named and optional input parameters.
 To complement this one you want to emulate named and optional parameters: define a struct that has fields that match the desired parameters

example
```go
type MyFuncOpts struct {
	FirstName string
	LastName string
	Age int
}
func MyFunc(opts MyFuncOpts) error {
	// doing somethign very important in here
}
func main() {
	MyFunc(MyFuncOpts {
		LastName: "Patel",
		Age: 50,
	})
	My Func(MyFuncOpts {
		FirstName: "Joe",
		LastName: "Smith",
	})
}
```
