The first difference that we’ll see between Go and other languages is that Go allows
for multiple return values.

one useful feature or more like a tradition is to use 2 different return values to almost every function
- the first value is the actual result of function
- the second is the indication of errors

```go
func divAndRemainder(numerator int, denominator int) (int, int, error) {
	if denominator == 0 {
		return 0, 0, errors.New("cannot divide by zero")
	}
	return numerator / denominator, numerator % denominator, nil
}
```

this is how we can take into account the possible errors generated by the defined function and handle the gracefully
```go
func main() {
	result, remainder, err := divAndRemainder(5, 2)
	if err != nil {
		fmt.Println(err)
		os.Exit(1)
	}
	fmt.Println(result, remainder)
}
```

## go doesn't work like python on multiple return values!
You must assign each value returned from a function. If
you try to assign multiple return values to one variable, you get a compile-time error

Ok what if we don't want to use all the return values?
- we can simply use the _ convention on variables that we don't need

One important thing to note: the name that’s used for a named returned value is local
to the function; it doesn’t enforce any name outside of the function. It is perfectly
legal to assign the return values to variables of different name
