You access all development tools through the go command
- compiler, code formatter, linter, dependency manager,test runner, etc


## go run
First setup an editor and enter the following text into it.
```go
package main
import "fmt"

func main() {
	fmt.Println("Hello, world!")
}
```
then you can just run the given program file by
```shell
go run hello.go
```

## go build
Most of the time you want to build a binary for later use. That’s where you use the go
build command. On the next line in your terminal, type:
```shell
go build hello.go
```
it creates a executable in the current directory
