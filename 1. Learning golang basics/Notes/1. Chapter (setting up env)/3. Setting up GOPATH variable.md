
on linux
```bash
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
```

on windows
```cmd
setx GOPATH %USERPROFILE%\go
setx path "%path%;%USERPROFILE%\bin"
```

Some online resources tell you to set the GOROOT environment
variable. This variable specifies the location where your Go devel‐
opment environment is installed. This is no longer necessary; the
go tool figures this out automatically
